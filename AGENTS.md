# Keera Docs

- Always be concise
- Omit the obvious
- Use simple language: short sentences, one idea per paragraph
- Explain each thing in one place, and link to it from the others
- Screenshots are WebP, in `docs/assets/images`, at twice the screen size.
  Mark them with `{ .screenshot }` so they get a frame
- Never add yourself to commits or commit messages
- The docs should focus on using and managing the public instance of Keera Gateway at https://gateway.keera.ch and Keera Chat at https://chat.keera.ch
- Format Markdown files with Prettier
